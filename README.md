# FinancialAnalysis
SQLServer analysis of sales,profit and profit margins
Analysis Performed

The project contains SQL queries covering the following areas:

Data exploration — Counted the total rows in the dataset.

Database inspection — Listed database tables and examined column names, data types and nullability.

Data preview — Retrieved sample records and identified distinct products.

Overall financial summary — Calculated total sales, cost of goods sold (COGS) and total profit.

Country-level analysis — Compared sales and profit across countries.

Profit margin analysis — Calculated profit margin percentages and ranked countries by total profit and profit margin.

SQL Skills Demonstrated

Aggregate functions such as COUNT() and SUM()

Metadata queries using INFORMATION_SCHEMA

SELECT DISTINCT and TOP

Grouping and sorting with GROUP BY and ORDER BY

Calculated metrics using CAST() and NULLIF()

Comparing total profit with profit margin

Key Findings

France ranked highest in total profit in my analysis.

Germany ranked highest in profit margin in my analysis.

These findings are specific to the sample dataset used in this project.
