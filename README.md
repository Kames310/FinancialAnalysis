# FinancialAnalysis
SQLServer analysis of sales,profit and profit margins
Financial Analysis Using SQL Server

Project Overview

This project explores sales and profitability using a financial sample dataset. The aim is to practise SQL analysis and identify differences in sales performance, total profit and profit margins.

Tools Used

Microsoft SQL Server

SQL Server Management Studio (SSMS)

SQL

Analysis

Calculated total sales and total profit.

Compared profitability across countries.

Calculated profit margin percentages.

Ranked countries by total profit and profit margin.

Key Findings

France ranked highest in total profit in the analysis.

Germany ranked highest in profit margin in the analysis.

Skills Demonstrated

SQL aggregation, GROUP BY, calculated metrics, NULL handling, sorting and ranking.

Note: Findings reflect the dataset analysed and are not intended to represent actual current country-level financial performance.
